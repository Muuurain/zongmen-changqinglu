# 《宗门长青录》产品需求文档（PRD）

## 1. 项目背景

传统古典仙侠题材的宗门经营模拟游戏。市面同类产品多为「挂机放置」或「数值碾压」式玩法，缺乏真正需要玩家持续决策的经营深度与长线传承感。本项目旨在打造一款**非挂机、决策有重量、世界动态演进**的中重度长线养成游戏：玩家从一座破败山门起步，通过弟子养成与势力征伐的双循环经营，最终执掌凡间界权柄、渡劫飞升、进军灵界。

## 2. 目标用户

- 喜爱修仙/仙侠题材、偏好经营模拟与策略养成的玩家
- 期望数十小时以上游玩周期的长线玩家
- 能接受回合制推进节奏、喜欢「每个选择都有后果」的硬核策略玩家

## 3. 核心功能

### 3.1 弟子深度养成（内部经营线）
- 招募（入门试炼/下山游历），筛选灵根、心性、气运、悟性
- 9 大境界 × 4 小阶段的境界体系，手动安排修炼与突破
- 突破有成功率与失败惩罚（掉境/走火入魔/根基受损/陨落）
- 职业方向 10 类（剑修/法修/体修/阵修/丹修/器修/符修/外事/传道/执法）
- 外出历练随机事件、道侣与后代、寿元与传承

### 3.2 宗门建设与产业
- 8 类建筑（山门/灵田/灵矿/演武场/丹房/藏经阁/弟子居/执法堂），手动升级
- 岗位配置驱动产出：无人驻守即停产，职业匹配影响效率

### 3.3 外交与战争（外部博弈线）
- 4 个 NPC 宗门动态关系（六级），赠礼/讲学/贸易/结盟/宣战
- 宗门攻防战：前中后排编队（职业加成）、4 种战术、护山大阵、战后三选一（灭门/附庸/合并）
- 附庸岁贡、安抚与反叛

### 3.4 贸易与经济
- 3 条商路，货款预付、风险与护送、归期结算

### 3.5 长线传承系统
- 长老院/客卿、派系斗争、底蕴气运、传承洞府
- 联盟组建、议事与讨伐
- 渡劫飞升、灵界分宗、全界大事件

## 4. 功能优先级

| 优先级 | 内容 |
|---|---|
| P0（已交付） | 核心闭环：招募→养成→突破→建筑产出→外交/战争→资源反哺 |
| P1（已交付） | 完整战争、商路、历练、长老院/派系、底蕴气运、联盟、渡劫飞升、灵界分宗、大事件 |
| P2（规划中） | 数值平衡细调、自定义图标与安装包打磨、成就/图鉴系统、更多随机事件与 NPC 宗门 |

## 5. 非功能需求

- **运行环境**：Windows（Electron 封装 exe）与浏览器（纯前端 `index.html`）双形态
- **性能**：单页应用，低内存占用；月度结算为纯数据运算，无网络依赖
- **可扩展性**：境界/建筑/事件/势力全部由 `data.js` 配置表驱动，便于批量扩充
- **存档**：localStorage 多槽位存档 + 自动存档 + 新周目，支持世代传承记录
- **可配置/可维护**：逻辑集中在 `game.js`（纯函数化模块）、UI 集中在 `ui.js`

## 6. 用户使用流程

1. 启动 → 山门初立（1 掌门 + 2 弟子 + 基础资源）
2. 招募弟子 → 分配岗位（灵田/演武场等）→ 点击「闭关一月」推进时间
3. 弟子修为满后手动突破（可服用丹药、请护法）
4. 发展外交（赠礼/结盟/宣战），发动宗门战争并选择战后处置
5. 派遣商队贸易、弟子外出历练
6. 壮大后任命长老、组建联盟、争取话语权
7. 贯通灵界通道 → 建立灵界分宗 → 大乘圆满渡劫飞升
8. 掌门坐化/飞升后自动传承下一代，长线经营

## 7. 验收标准

| 验收项 | 标准 |
|---|---|
| 核心循环跑通 | 能「产资源→养弟子→对外博弈→获更多资源」持续运转 |
| 非挂机 | 不点击「闭关一月」无任何产出；离线零收益 |
| 决策后果 | 突破/战争/外交/事件均有明确收益与风险，且失败有实际惩罚 |
| 世界演进 | NPC 宗门会自主发展、攻伐、劫掠玩家 |
| 传承 | 掌门坐化/飞升后道统延续、代数递增 |
| 存档 | 刷新后进度保留、多周目可重置 |
| 打包 | 产出可运行的 Windows exe |
