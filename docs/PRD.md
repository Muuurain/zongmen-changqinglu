# 《宗门长青录》产品需求文档（PRD）

## 1. 项目背景

传统古典仙侠题材的宗门经营模拟游戏。市面同类产品多为「挂机放置」或「数值碾压」式玩法，缺乏真正需要玩家持续决策的经营深度与长线传承感。本项目旨在打造一款**非挂机、决策有重量、世界动态演进**的中重度长线养成游戏：玩家从一座破败山门起步，通过弟子养成与势力征伐的双循环经营，最终执掌凡间界权柄、渡劫飞升、进军灵界。

## 2. 目标用户

- 喜爱修仙/仙侠题材、偏好经营模拟与策略养成的玩家
- 期望数十小时以上游玩周期的长线玩家
- 能接受回合制推进节奏、喜欢「每个选择都有后果」的硬核策略玩家

## 3. 核心功能

### 3.1 弟子深度养成（内部经营线）
- 招募（入门试炼/下山游历），筛选灵根、心性、气运、悟性
- 9 大境界 × 4 小阶段的境界体系，手动安排修炼与突破
- v1.2.0：弟子名录提供一键自动突破、个人参与开关、直接/服丹/等丹策略及可选月结执行；九雷渡劫维持手动。灵根统一为五行单属性天灵根、雷冰风异灵根和二至五属性多灵根，属性越多修炼越慢，宗门实力与声望提高招募资质概率。具体已实现规则见 `v1.2.0-自动突破与灵根重构.md`。
- v1.2.1：更新修炼、突破、渡劫与剑斗帧动画，替换过时插画和建筑图标；新增动画须保留透明通道、按精灵图网格切片，并提供 reduced-motion 降级。资源及兼容处理见 `v1.2.1-动画美术资源接入与修复.md`。
- v1.2.2：新增开始界面（继续/开创/读档）与自定义初代宗主（姓名、性别、宗门名）；弟子生命周期闭环——人物生平留档（时间线/离宗原因/战力快照）、人物留档只读区、强敌交战战损 5% 概率陨落、逐出山门（不可召回）。存档格式号保持 3，旧档自动迁移。详见 `弟子生命周期与开始界面_代码交接_2026-10-26.md`。
- 突破有成功率与失败惩罚（掉境/走火入魔/根基受损/陨落）
- 职业方向 10 类（剑修/法修/体修/阵修/丹修/器修/符修/外事/传道/执法）
- 外出历练随机事件、道侣与后代、寿元与传承

### 3.2 宗门建设与产业
- 8 类建筑（山门/灵田/灵矿/演武场/丹房/藏经阁/弟子居/执法堂），手动升级
- 岗位配置驱动产出：无人驻守即停产，职业匹配影响效率

### 3.3 外交与战争（外部博弈线）
- 4 个 NPC 宗门动态关系（六级），赠礼/讲学/贸易/结盟/宣战
- 宗门攻防战：前中后排编队（职业加成）、4 种战术、护山大阵、战后三选一（灭门/附庸/合并）
- 附庸岁贡、安抚与反叛

### 3.4 贸易与经济
- 3 条商路，货款预付、风险与护送、归期结算

### 3.5 长线传承系统
- 长老院/客卿、派系斗争、底蕴气运、传承洞府
- 联盟组建、议事与讨伐
- 渡劫飞升、灵界分宗、全界大事件

### 3.6 多平台形态（v1.2.3）
- Windows：Electron 封装 exe（NSIS 安装包 + 便携版）
- Android：Capacitor 封装 APK（Android 7.0+），窄屏/横屏布局、触控、系统返回键、前后台自动保存与音乐暂停恢复、原生存档桥接（首次启动迁移旧 localStorage 存档）
- 浏览器：直接打开 `index.html`（存档保存在浏览器 localStorage）
- 三个形态共享同一份网页源码与游戏逻辑，版本号同步维护

## 5. 非功能需求

- **运行环境**：Windows（Electron 封装 exe）、Android（Capacitor 封装 APK，API 24+）与浏览器（纯前端 `index.html`）三形态
- **性能**：单页应用，低内存占用；月度结算为纯数据运算，无网络依赖
- **可扩展性**：境界/建筑/事件/势力全部由 `data.js` 配置表驱动，便于批量扩充
- **存档**：localStorage 多槽位存档 + 自动存档 + 新周目，支持世代传承记录
- **可配置/可维护**：逻辑集中在 `game.js`（纯函数化模块）、UI 集中在 `ui.js`

## 6. 用户使用流程

1. 启动 → 开始页（继续上次修行 / 开创新宗门 / 读取存档）→ 山门初立（1 掌门 + 2 弟子 + 基础资源，初代宗主可自定义姓名、性别与宗门名）
2. 招募弟子 → 分配岗位（灵田/演武场等）→ 点击「闭关一月」推进时间
3. 弟子修为满后手动突破（可服用丹药、请护法），或使用自动突破面板批量执行
4. 发展外交（赠礼/结盟/宣战），发动宗门战争并选择战后处置（战损有 5% 陨落风险）
5. 派遣商队贸易、弟子外出历练；对违纪或冗余弟子可逐出山门
6. 壮大后任命长老、组建联盟、争取话语权
7. 贯通灵界通道 → 建立灵界分宗 → 大乘圆满渡劫飞升
8. 掌门坐化/飞升后自动传承下一代；陨落/逐出/离宗人物留档可查阅生平，长线经营

## 7. 验收标准

| 验收项 | 标准 |
|---|---|
| 核心循环跑通 | 能「产资源→养弟子→对外博弈→获更多资源」持续运转 |
| 非挂机 | 不点击「闭关一月」无任何产出；离线零收益 |
| 决策后果 | 突破/战争/外交/事件均有明确收益与风险，且失败有实际惩罚 |
| 世界演进 | NPC 宗门会自主发展、攻伐、劫掠玩家 |
| 传承 | 掌门坐化/飞升后道统延续、代数递增 |
| 存档 | 刷新后进度保留、多周目可重置 |
| 打包 | 产出可运行的 Windows exe |
