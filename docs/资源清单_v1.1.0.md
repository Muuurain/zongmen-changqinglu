# 《宗门长青录》v1.1.0「画面焕新」资源需求清单

> 版本目标：解决玩家反馈「文字过多、图像与动画过少」，全面视觉化改版。  
> 本文档仅列出**当前 `assets/` 目录尚未拥有的资源**；已存在的 30 项资源（4 头像、7 背景、8 建筑图标、2 BGM、7 SFX、2 UI 件）不在此列。  
> 使用方式：每项资源附带完整生成提示词，可直接交给生成型 Agent 制作；制作完成后按「存放路径」落盘，主 Agent 再接入并做界面/动画开发。

## 通用规范

| 项     | 规范                                                              |
| ----- | --------------------------------------------------------------- |
| 命名    | 全小写 ASCII 蛇形命名（snake_case），含子目录前缀，禁止中文与空格                       |
| 图片格式  | 背景/插画用 PNG（可带透明通道则 PNG）；帧动画用 PNG sprite sheet                   |
| 音频格式  | BGM 用 MP3（128–192kbps 循环友好，首尾可淡入淡出）；SFX 用 MP3，时长 < 3s           |
| 美术风格  | 统一「中国传统水墨 + 仙侠」：宣纸质感、留白、墨色晕染，点缀青绿/赭石/金色；人物工笔淡彩；不得混入西式魔幻/赛博朋克元素  |
| 分辨率基准 | 游戏窗口 1280×800；插画按 960×540（16:9），头像 256×256，图标 128×128（输出后程序内缩放） |
| 版权    | 全部 AI 原创生成，不得含真实人物、商标、水印                                        |

## 接入说明（供后续开发参考）

1. 所有文件命名必须为 ASCII（规避 gh CLI 中文资产问题与 Windows 路径编码坑）。
2. 图片交付后统一跑一遍校验：PNG 签名/IHDR 尺寸/MD5 去重；音频校验 MP3 头与时长。
3. sprite sheet 在 CSS 中以 `background-position` + `animation: steps(N)` 播放，无需 JS 逐帧驱动。
4. 既有 `assets/` 根目录文件保持不动；新文件进子目录后，代码中路径相应更新为 `assets/ill/...` 等。
