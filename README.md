# 宗门长青录

> 传统古典仙侠背景的宗门经营模拟游戏。融合「弟子深度养成 + 宗门道统传承」的内部经营线，与「外交贸易 + 征伐收服」的外部博弈线，形成内外双循环闭环。**非挂机设计**——一切成长由玩家决策驱动。

## 游戏特色

- **四大成长阶段**：山门初立（炼气~金丹）→ 宗门兴盛（元婴~化神）→ 雄霸一方（炼虚~合体）→ 万古长青（大乘~飞升）
- **弟子深度养成**：9 大境界 × 4 小阶段、五行/变异/天灵根、心性气运、手动突破（失败有掉境/走火入魔/陨落风险）、外出历练、寿元传承
- **宗门建设**：灵田、灵矿、演武场、丹房、藏经阁等 8 类建筑，岗位配置决定产出
- **外交博弈**：4 个 NPC 宗门关系动态演进，赠礼/讲学/贸易/结盟/宣战
- **宗门战争**：前中后排编队（职业加成）、四种战术、护山大阵、战后灭门/收附庸/合并三选一
- **经营贸易**：商路护送与劫掠风险、附庸岁贡与反叛
- **长线传承**：派系斗争、长老院/客卿、底蕴气运、传承洞府、联盟议事与讨伐
- **飞升结局**：九道天雷渡劫、灵界分宗、全界大事件（魔道入侵/上古秘境/域外天魔）

## 运行方式

### 方式一：Windows 安装包（推荐）
从 [Releases](../../releases) 下载最新版 `ZongMenChangQingLu-Setup-x.x.x.exe`（NSIS 安装包），安装后运行。

### 方式二：Windows 便携版
从 [Releases](../../releases) 下载 `宗门长青录-win32-x64.zip`，解压后双击 `宗门长青录.exe`。

### 方式三：浏览器直接游玩
双击打开 `index.html` 即可（存档保存在浏览器 localStorage）。

### 方式四：从源码运行
```bash
npm install
npm start
```

## 打包

```bash
# 便携版（无需管理员权限）
npm run build:portable

# NSIS 安装包（若报符号链接权限错误，改用管理员终端运行）
npm run dist
```

## 设计原则

- **拒绝纯挂机**：时间以「月」为单位，仅在点击「闭关一月」时推进；离线零产出
- **决策有重量**：所有关键选择均有收益与风险，不存在无代价最优解
- **世界动态化**：NPC 宗门自主发展、攻伐、劫掠，玩家搁置会承受后果
- **传承长线感**：宗门寿命远超单个修士，掌门坐化后道统延续

## 技术栈

纯前端原生 HTML/CSS/JavaScript（配置表驱动），Electron 封装 Windows 桌面端，electron-builder / 自研脚本双打包通道。
